# 按钮位置与功能差异（v5）

参考用户提供的 WPS Writer/Calc 截图。Draw 没有独立 WPS 绘图截图，采用相同的顶部功能区、字体与形状操作习惯，保留 LibreOffice 绘图工具和属性面板。

| 区域 | 已处理 | 剩余差异 |
| --- | --- | --- |
| 开始：格式刷与剪贴板 | 格式刷置左，粘贴随后，剪切复制用小图标 | 间距、粘贴菜单和图标仍是 LibreOffice |
| 开始：字体 | 字体字号、上标下标、清除格式集中；Draw 新增字体区 | 字号显示、可用字体和文档默认值取决于原生组件；可选模板提供宋体 |
| Writer 段落与样式 | 缩进、段落标记移入段落区；行距在下行；保留样式预览和样式窗格 | 样式预览数量和侧栏样式列表不同，安装后侧栏可能需要点击打开 |
| Calc 对齐与常用操作 | 对齐后是换行与合并；填充和冻结使用实际菜单 | 小窗口收进溢出区；选择范围决定菜单是否可用 |
| Calc 填充 | 上下左右和序列填充 | “数据”页的向下填充是单个动作，不能称作完整填充菜单 |
| Calc 冻结 | 冻结/取消当前位置、冻结首行、冻结首列 | 原生首行与首列动作可叠加，按第一项取消；当前位置取决于活动单元格 |
| Draw 开始与工具 | 字体、文本框、形状填充、轮廓、对齐、分布、组合、旋转、层级、PDF | 原生绘图工具栏、菜单栏、图层与上下文页保留；没有 WPS 专属素材 |
| 插入/页面/引用/审阅/视图 | 各配置分组占用独立原生容器，按参考顺序安排命令 | 原生行高、空分隔线、下拉控件及运行时名称覆盖仍存在，不能宣称精确两行复刻 |
| Calc 公式 | 函数向导、函数列表、名称、追踪与重算 | 没有 WPS 财务/逻辑/文本等独立分类菜单；可用函数列表筛选分类 |
| 页面与打印 | 页边距、方向、大小、打印网格线等入口可进入原生页面设置 | 多个入口可能显示相同“页面格式”名称并打开同一窗口，必须在窗口中选择选项 |
| 保护与区域 | 保留准确原生命令语义 | 单元格格式的保护页不是锁定开关；数据库区域不是 WPS 结构化表格 |
| 只读与分页 | 名称改为“只读模式”“分页符” | 只读模式不是 WPS 阅读视图；分页符不会保证生成独立空白页 |

CSV 中的文字是配置意图，LibreOffice 可能按命令注册信息显示原生名称。“已安排”仅表示入口写入相应容器，不表示该动作在所有选区、文档和状态下都可用。

没有已确认直接对应动作的朗读、限制编辑、允许编辑区域、重排窗口等入口未伪装实现。精准重排必须保留原生容器并逐页验证：直接替换整页容器的试验曾产生空白功能区，未纳入交付。
