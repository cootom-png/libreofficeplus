# WPS 习惯适配计划与进度

目标是减少 WPS 用户寻找常用按钮和学习新操作的成本。Writer、Calc 参考所提供截图；Draw 采用同样的视觉组织，结合原生绘图上下文。

| 工作项 | v5 交付状态 | 验收依据或下一步 |
| --- | --- | --- |
| 固定版本与命令清单 | 已交付 | 三模块基线校验；保留精确构建检查 |
| 选项卡顺序与中文名称 | 已交付 | 三模块 UI 结构检查及实际开始页预览；共 100 项名称属性，非 100 个新功能 |
| 开始页分组、两行常用操作 | 已交付 | `config/home.json`、实际窗口；Writer 段落、Calc 对齐、Draw 字体区已调整 |
| 非开始页逐组安排 | 已交付基础分组 | 每组使用独立原生容器；原生间距、控件大小、空分隔线和运行时名称仍有差异 |
| 常用下拉菜单 | 已交付填充、冻结、选择 | 冻结首行与首列通过 GUI；填充四方向通过文档结果验证 |
| Writer 常用冲突键位 | 已交付 3 项 | Ctrl+D、F12、F4 在实际安装的独立配置中读取验证；其他键位保留 |
| 模板与字体习惯 | 已交付可选模板 | 三个模板成功加载；不修改默认模板或现有文档 |
| Draw 页面风格 | 已交付 | 开始/插入/页面/审阅/视图/工具分组；矩形绘制、绘图上下文和属性栏通过 GUI 检查 |
| 安装、备份、部分恢复 | 已交付 | 模块安装追加、逐模块恢复、首次备份、v3/v4 升级、故障撤回检查 |
| 常用原生操作 | 已交付基础验证 | v6.2 共 100 项：48 项操作/模板、47 项键位读取、5 项按映射派发；见单独记录 |
| 多窗口宽度 | 已检查普通与最大化 | Writer/Calc 窄窗口采用原生溢出；其他分辨率与 125%/150% 显示缩放未穷尽 |
| 常用右键菜单 | v6 已重排 16 类 | 按对象与操作分组，保留所有命令及动态控制器；未逐像素复刻 WPS |
| 弹窗入口与文件窗口 | v6 已实现 | 字体/段落/单元格/形状设置集中，系统打开与保存窗口 |
| 原生弹窗内部布局 | 设计完成，尚未实现 | 字体 → 段落 → 单元格 → 页面 → Draw；见 [弹窗菜单设计](弹窗菜单设计.md)，需源码构建或完整扩展 |
| 所有页的精确两行位置 | 尚未完成 | 应逐页保留原生容器改内部排列；每页进行正常/窄窗口和上下文切换验证后纳入 |
| 函数分类菜单 | 原生函数列表替代 | 尚无 WPS 分类弹出菜单；后续须验证分类参数与函数实际插入，不能添加同名空入口 |
| 完整文档兼容与真实打印 | 尚未完成 | 后续采用脱敏 DOCX/XLSX/ODG 样例，验证版式、公式、图形和 PDF/打印结果 |
| WPS AI/云/会员/素材/顶部跨文档标签 | 未实现 | 不属于当前原生配置包可直接复用的功能 |

执行顺序为“原生基线 → 配置与构建 → 隔离安装/恢复 → 原生文档操作 → 实际窗口 → 中文 PR”。本版能安全交付的改动已纳入同一 PR；上表明确列出未达到精确复刻的项目，不能将方案条目本身当成已实现功能。

后续应先逐页减少空容器和统一行高，再实现有真实功能的函数分类及弹窗内部原型。验收需同时记录参考位置、实际位置、命令行为、窄窗口结果和恢复结果，不以按钮数量作为完成率。
