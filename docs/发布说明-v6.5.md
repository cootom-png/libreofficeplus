LibreOfficePlus v6.5.0 将 Impress 演示加入同一套配置包，适配 Windows LibreOffice 26.2.5.2（构建 `cd7284b4cbbfeb507e630c1aac019f4157393acb`）。

- 文件、开始、插入、设计、切换、动画、放映、审阅、视图、工具按常见演示习惯排列；开始页集中幻灯片、字体、段落、形状和放映入口。
- 切换和动画分别进入 LibreOffice 原生侧栏；保留表格、图片、母版、绘图、媒体上下文页和扩展页。
- 新增 8 类演示右键菜单，原生命令、可用条件和动态子菜单完整保留。
- Ctrl+M 新建幻灯片，Ctrl+G / Ctrl+Shift+G 组合/取消组合，Shift+F9 网格，F12 另存为，Ctrl+Alt+V 选择性粘贴；保留 F5 / Shift+F5 原生放映键位。Ctrl+D 的上下文行为没有被全局覆盖。
- 安装窗口新增“Impress 演示”，支持单独配置、旧版追加和按模块恢复；首次备份继续保留。新增独立 16:9 空白演示模板，不改写已有 PPT 或默认模板。

下载 `LibreOfficePlus.zip`，完整解压，保存文档并退出 LibreOffice 后双击 `安装.vbs`。只配置演示可仅勾选 Impress；命令入口支持 `安装.cmd -Modules Impress`。恢复使用 `恢复原界面.vbs`。其他版本或构建会被兼容检查阻止。

验证范围与待验收项见 [演示适配与验收](https://github.com/cootom-png/libreofficeplus/blob/v6.5.0/docs/演示适配.md)。可见 Impress 测试实例无法连接，按钮逐项点击、动画预览、真实全屏放映、隐藏幻灯片选区和显示缩放仍待验收；无界面命令与简单 PPTX 往返不证明所有演示兼容性。原生弹窗内部没有重绘，旧 Writer 窄文字框重排风险仍存在。

界面与新增分组独立设计，使用 LibreOffice 原生命令和 Colibre 图标；没有加入 WPS 商标图形、图标、字体、程序代码或截图。WPS 名称仅说明习惯参考。原生 UI 和菜单来源、校验值与 MPL 2.0 许可随包提供。

发布包含配置包、SHA256SUMS.txt 与 release.json，通过 GitHub Actions 从最新 main 的完整提交构建并校验公开下载。对话授权作为发布批准记录；仓库未配置分支/环境审批保护，不宣称已有保护。工作流临时产物保留 7 天，已有标签和版本资产禁止覆盖，回退可使用 v6.4.1 并先恢复本机首次备份。
