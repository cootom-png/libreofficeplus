# LibreOfficePlus v6.8.1

修复当前 LibreOffice 26.2.6.3 被安装器拒绝的问题，并改善“已经退出软件仍提示运行中”的排查信息。沿用 v6.8.0 的 Material 外观、WPS 操作布局及快捷键。

- 增加 26.2.6.3 的精确构建支持：`8221e31b3ac356a1623c672912a3d2b492f7e3d1`。官方标签、本机产品版本和构建匹配，28 个原生界面/菜单文件与现有基线一致；未放行其他未知构建。
- 安装、恢复和兼容升级共用进程识别。明确属于其他应用的同名更新器不会误拦截；LibreOffice 文档进程及官方更新器仍阻止修改。路径无法核验时保守停止。
- 运行状态失败时显示实际进程名称、PID 与可读取的路径，便于查看后台残留。关闭软件后请重新运行安装入口，旧失败窗口不会自动刷新上次结果；不会强制结束进程。
- 菜单选中背景改为浅蓝、选中文字改为黑色，兼顾 Windows 仍使用系统蓝色背景时的文字对比度；不修改 Windows 主题。
- 修正开发用 Material 预览的宏处理方式，让空白文档遵循现有安全设置，不再产生误导的宏禁用提示；没有降低用户宏安全级别，也没有屏蔽真实含宏文档的安全警告。

支持 Windows x86-64 版 26.2.5.2、26.2.6.1、26.2.6.3 与 26.8.1.1。下载完整配置包，保存文档并退出 LibreOffice，解压后双击 `安装.vbs`，选择此前使用的全部模块；首次恢复备份继续保留。

验证包括进程识别回归、安装/恢复与版本切换、图形窗口及隔离模拟升级检查，并在 26.2.6.3 的独立配置中核验原生命令、菜单、演示往返、外观安装/恢复及更新开关。复杂旧文档重排、原生弹窗内部布局、顶部选项卡宽度和真实 MSI/UAC/重启仍保留既有边界。
