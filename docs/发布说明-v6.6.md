# LibreOfficePlus v6.6.0：新旧版本兼容

同一配置包支持原有 LibreOffice **26.2.5.2** 和最新稳定版 **26.8.1（完整版本 26.8.1.1）**。安装自动核对产品版本与构建，并选用各自的 Writer、Calc、Draw、Impress 功能区和菜单；旧版界面资源保持不变。

- 新版采用对应原生网格控件，保留字体、段落、数字、样式和上下文页，继续提供熟悉的选项卡、格式刷和常用入口。
- 升级或降级时检查所有已配置模块，防止新旧文件混用。重复安装、切换版本与按模块恢复均保留首次备份；未知构建和资源缺失会停止写入。
- 图形安装展示实际版本与匹配资源；发布元数据增加完整兼容矩阵，下载核验检查矩阵、文件和 SHA-256 一致。
- 两版分别通过 114 项基础原生回归、102 项演示检查及 30 项菜单/外观读取，另有每版 2 项演示可见选区检查待完成。安装、恢复、旧备份迁移、新旧切换及 WPF 检查通过。以上测试有重叠，不合计为功能总数。

解压完整 `LibreOfficePlus.zip`，双击 `安装.vbs`。升级本体后、首次打开文档前，**勾选此前配置过的所有模块**重新配置。配置包不会替换或升级 LibreOffice 本体。

新版真实窗口逐项点击、不同缩放和全屏动画尚未完整验收；旧文档窄文字框样式重排风险仍未修复。复杂文档先用副本检查。详见包内 `版本兼容.txt` 和仓库兼容说明。

发布资产仅含配置包、`SHA256SUMS.txt` 与 `release.json`；保留 v6.5.0 供核对和回退，禁止覆盖已发布标签。工作流临时产物保留 7 天。沿用本对话用户对实施、PR 与发布的明确授权；不声称仓库存在未配置的 GitHub 审批保护。
