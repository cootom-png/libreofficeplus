# WPS 用户操作习惯（v6.2）

本版配置 22 个键位：Writer 10 个、Calc 8 个、Draw 4 个。完整清单随包提供“快捷键对照表.csv”。按所选模块安装并备份对应键位；恢复时还原首次配置，其他个人快捷键保留。表格与绘图键位分别归属自己的模块，不按共享设置写入。

## 本版应用的键位

| 模块 | 键位 | 动作与差异 |
| --- | --- | --- |
| 三模块 | F12；Ctrl+Alt+V | 另存为；选择性粘贴。粘贴内容为空时命令可能不可用 |
| Writer | Ctrl+D | 字体窗口 |
| Writer | Ctrl+Shift+G | 字数统计 |
| Writer | Ctrl+1；Ctrl+2 | 单倍行距；双倍行距，替换原来的标题 1/标题 2 样式快捷键 |
| Writer | Ctrl+=；Ctrl+Shift+= | 下标；上标。等号键指主键盘，不是数字小键盘加号 |
| Writer | Ctrl+Shift+E | 开启/关闭修订，替换原来的脚注区域跳转 |
| Writer | F4 | 重复上一步原生支持的操作，不能保证重复所有 WPS 操作 |
| Calc | Ctrl+R | 向右填充，替换原来的右对齐；先选包含源单元格的范围 |
| Calc | Ctrl+G；F5 | 将焦点移到名称框，输入 A1 或 A1:C3 后回车定位；不是 WPS 的完整定位/定位条件窗口 |
| Calc | Ctrl+Shift+= | 插入单元格窗口，主键盘等号键 |
| Calc | Alt+= | 自动求和，范围识别与确认过程沿用 Calc |
| Calc | F11 | 打开原生图表向导，需继续确认；与 WPS 直接生成图表的过程有差异 |
| Draw | Ctrl+G；Ctrl+Shift+G | 组合；取消组合，参照 WPS 对象操作。组合前至少选择两个对象 |

## 已经相同的原生键位

Ctrl+C/X/V、Ctrl+S、Ctrl+Z/Y 不重复覆盖。表格的 Ctrl+D 向下填充、Ctrl+1 单元格格式、Ctrl+Shift+L 筛选、Ctrl+; 日期、Ctrl+Shift+; 时间继续使用原生映射。Draw 的 F4 仍打开大小和位置。其他原生键位及已有个人设置不批量重置。

## 尚有差异的编辑行为

- Calc 的 F4 保留公式相对/绝对引用切换。WPS 非公式状态下重复行列操作的 F4 未实现，不能直接覆盖引用切换。
- WPS 表格 Alt+Enter 单元格内换行、Ctrl+Enter 批量输入未通过简单键位配置复刻；Calc 单元格内换行仍用 Ctrl+Enter。不同编辑状态的处理需要扩展或源码支持。
- Writer 的 Ctrl+Shift+C/V 复制/粘贴格式未实现，不把格式刷启动键冒充完整的两步格式复制；Ctrl+Shift+V 继续是原生选择性粘贴。Ctrl+Alt+V 提供熟悉的选择性粘贴入口。
- WPS 多文档标签切换、AI、云功能与宏专属键位未映射；新键位不改变 LibreOffice 的文档引擎或宏安全设置。

## 验证与来源

新建键位使用原生 Key 集合节点写入，兼容软件保存后的节点、单键属性及本地化值形式。独立实例读取 22 个已配置键位和 25 个保留键位；行距、上下标、修订另外按有效映射派发并读取结果。配置读取、命令派发与实际键盘输入分别记录，不互相冒充。
