LibreOfficePlus v6.4.1 改进常用操作与安装体验，适配 Windows LibreOffice 26.2.5.2，构建 `cd7284b4cbbfeb507e630c1aac019f4157393acb`。

v6.4.1 将正式发布文件统一为 `LibreOfficePlus.zip`，修复 GitHub 自动规范化中文文件名后，下载文件名与校验清单不一致的问题。发布流程会下载已发布资产，核对名称、完整提交、版本号、SHA-256 和包内全部文件后才判定成功。仓库原下载路径继续保留。

- 安装前选择 Writer、Calc、Draw，查看模板字体提示、修改安装目录，再开始检查与配置；空选择会阻止操作。完成后可查看可选模板。
- Writer 增加“样式检查”入口与段落样式说明；将“字体（文字外观）”与段落设置区分。
- Calc 增加粘贴值、仅粘贴格式、仅粘贴公式和完整选择性粘贴入口。粘贴值包含文本、数字、日期序列值及公式计算结果，保留目标格式。
- 将“附件”纠正为“嵌入对象”，“文档”纠正为“从文件导入工作表”，使名称符合实际动作。
- 常用操作两行增加一致间距；收起已清空的按钮容器，保留其他原生控制器。Draw 默认收起传统菜单栏，可从右上角菜单重新显示，也支持恢复原设置。
- 新增通过 GitHub Actions 发布的固定版本下载、完整提交信息和 SHA-256 校验清单。

请完整解压 ZIP，先保存文档并退出 LibreOffice，再双击 `安装.vbs`。已安装用户直接重复安装；首次备份继续保留。恢复使用 `恢复原界面.vbs`，也可只恢复所选模块。安装程序不会强制结束软件。

本项目独立设计操作分组和安装界面，使用 LibreOffice 原生命令与 Colibre 图标；未加入 WPS 商标图形、图标、字体、程序代码或截图。WPS 名称仅说明操作习惯参考；项目与 WPS、The Document Foundation 均无隶属或官方合作关系。原生资源来源与 MPL 2.0 许可证随包提供。旧 ZIP 文件名为保持下载兼容继续保留。

仍有边界：旧文档的窄文字框应用样式后可能重排，样式检查入口不是文档引擎修复；原生弹窗内部布局、编辑状态相关快捷键和跨文档标签切换留待后续。其他版本未验证，安装会拒绝不匹配构建。

发布只包含配置包、`SHA256SUMS.txt` 与 `release.json`。首次备份由用户本机保管；工作流临时构建产物保留 7 天，已有版本标签和资产禁止覆盖。需要回退时先恢复首次备份，再选择旧提交提供的配置包，并核对该版本的兼容要求。
