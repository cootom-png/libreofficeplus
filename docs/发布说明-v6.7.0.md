# LibreOfficePlus v6.7.0：兼容升级与官方提醒管理

- 安装后关闭当前用户的 LibreOffice 自动升级提醒、自动下载和 MAR 增量自动更新。原值纳入首次备份，最后一个模块恢复时还原。
- 新增蓝白图形入口 `兼容升级.vbs`，仅允许升级到本包适配清单中的完整版本和构建；不自动降级。
- 当前支持从 26.2.5.2 或 26.2.6.1 升级到 26.8.1.1。官方 MSI 缓存到本机，按固定 SHA-256 和官方数字签名验证后才执行。
- 升级前保留界面、设置和首次恢复记录，安装后核对实际构建，自动重新配置原有全部模块。失败或要求重启时保留进度，再次运行可继续。
- 安装、恢复与升级统一检查独立更新程序，运行时停止，避免配置期间本体被替换。
- 增加“获取新版配置包”入口，打开本项目正式发布页。未适配版本不会被当作可升级版本。

解压完整 ZIP，先运行 `安装.vbs` 更新原有模块设置；今后通过 `兼容升级.vbs` 升级。没有更高兼容版本时保持现状，不重复安装。本版适配 26.2.5.2、26.2.6.1 与 26.8.1.1。

用户设置不拦截企业部署、其他用户、手动安装或外部软件管理器。升级可能需要 Windows 管理员授权；本助手不自动回滚本体。真实 MSI 安装、UAC 与重启尚需目标环境验证，测试使用隔离模拟，不替代实机升级验收。详情见包内“兼容升级.txt”。

选项卡间距和旧文档标题样式重排仍是已有本体限制，本版没有宣称修复。

本次合并与发布使用用户在对话中对本项目持续实施、提交及发布更新的明确授权。经 GitHub Actions 对最新 main 的完整提交构建、检查和发布，再下载正式资产核验；不声称存在未配置的 GitHub 环境审批。工作流临时产物保留 7 天，既有正式版本和首次恢复备份继续保留。
