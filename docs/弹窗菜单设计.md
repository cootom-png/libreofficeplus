# 弹窗与弹出菜单适配（v6）

目标是让常用设置从熟悉的位置打开，按操作对象组织菜单，减少层级。现有参考图是 WPS 顶部功能区，没有字体、段落、单元格格式等弹窗或右键菜单截图，因此下面是操作习惯适配，不能称为逐项对照复刻。

## 本版实际实现

| 场景 | 顺序与分组 |
| --- | --- |
| Writer 文字右键 | 剪切/复制/粘贴/选择性粘贴 → 字体/段落/样式/格式刷/清除格式 → 超链接 → 批注/修订 → 页面设置；其余上下文命令保留 |
| Writer 表格右键 | 剪贴板 → 插入/删除/合并/拆分/行列尺寸/表格属性 → 字体/段落/样式 → 超链接 → 批注/修订；其余命令保留 |
| Writer 图片右键 | 剪贴板 → 裁剪/更换/压缩/保存图片 → 图片属性 → 层级/对齐/旋转 → 锚定/环绕/题注 |
| Calc 单元格右键 | 剪贴板 → 插入/删除/清除内容/合并/拆分 → 设置单元格格式/格式刷/清除格式/样式 → 数据相关动作 → 批注；迷你图和条件格式仍保留 |
| Calc 行、列标题 | 剪贴板 → 插入/删除/清除 → 行高或列宽/最适尺寸/隐藏/取消隐藏 → 单元格格式 → 冻结/拆分窗口 |
| Calc 工作表标签 | 插入/删除/重命名/复制/移动 → 选择工作表 → 标签颜色/隐藏/显示/保护 → 网格/方向/事件 |
| Calc 图形、图片 | 剪贴板 → 填充/轮廓/大小或图片操作 → 层级/对齐/组合/旋转 → 锚定 → 超链接；宏和签名等高级命令保留 |
| Draw 形状、组合、多选 | 剪贴板 → 填充/轮廓/大小和位置 → 层级/对齐/分布/组合/旋转；转换及对象信息等命令保留 |
| Draw 文字、图片 | 文字：剪贴板 → 字体/段落/编号 → 文本属性 → 链接；图片：剪贴板 → 图片操作 → 大小/轮廓 → 层级/对齐/组合/旋转 |
| Draw 页面、缩略图 | 页面：剪贴板 → 页面设置/背景/布局 → 标尺/网格/参考线；缩略图：剪贴板 → 新建/复制/删除/重命名页面 |

共覆盖 16 个原生菜单资源。命令是否显示或可用仍由当前选区和 LibreOffice 上下文决定；动态子菜单不展开成固定动作。配置重排保留全部原有命令及属性，不以删除高级功能来缩短菜单。

独立窗口实测截图：[Writer 文字菜单](writer-popup.jpg)、[Calc 单元格菜单](calc-popup.jpg)、[Draw 形状菜单](draw-popup.jpg)。截图仅含自建测试内容。

开始页新增 Writer“格式设置”下拉、Draw“形状设置”下拉，集中常用弹窗入口；Calc 常用区增加“单元格格式”。下拉菜单用分隔线区分常用动作与进一步设置。菜单显示 Colibre 图标及可用快捷键；打开与另存为使用 Windows 系统文件对话框，便于继续使用收藏位置、路径栏和常见文件夹。

## 弹窗内部重新设计的范围与后续顺序

字体、段落、单元格格式、页面、打印、形状属性等窗口仍为原生窗口，本版调整的是入口、名称及文件窗口选择，**没有重排这些原生窗口内部的控件，也没有统一其圆角、配色和尺寸**。一键配置只能覆盖菜单与功能区；普通对话框从程序安装资源加载，不能把 notebookbar 的用户覆盖机制直接套用到所有 `.ui` 文件上。

| 顺序 | 后续目标布局 | 必须验证的行为 |
| --- | --- | --- |
| 1 | 字体：上方字体/字号/字形，中部颜色及效果，下方预览；中文字号与磅值关联 | 中文与西文字体、多选混合值、预览、确定、取消、撤销 |
| 2 | 段落：对齐 → 缩进 → 段前段后/行距 → 预览；分页与换行单独页 | 字符/厘米单位、首行缩进、固定值与倍数行距、分页属性 |
| 3 | 单元格格式：数字/对齐/字体/边框/填充/保护六类 | 自定义数字格式、跨区域选区、样式继承、保护页不会误写成保护开关 |
| 4 | 页面设置：页边距/纸张/版式，表格另有工作表与打印范围 | A4/方向、缩放、打印标题、页眉页脚、PDF 和实际打印预览 |
| 5 | Draw：填充/轮廓/大小与位置/文本四类 | 组合对象、多选混合值、渐变透明度、长宽比、旋转与撤销 |

这些内部布局需要 LibreOffice 源码构建，或单独实现能完整处理文档选区和撤销的扩展窗口。应先完成字体与段落的小范围原型，再逐类纳入；不能用只改标题、同名空面板或覆盖安装目录的零散资源文件冒充完成。当前包不改写 Program Files，也不降低宏或系统安全策略。

## 复现与恢复

`config/popups.json` 保存菜单分组；`vendor/libreoffice/SOURCE.json` 记录固定版本及原始文件校验值；`scripts/popups.py` 构建用户覆盖文件。新增文件与原有功能区一起按模块备份；v4/v5 的首次功能区备份仍可继续使用。恢复某个模块时恢复该模块原有菜单，安装前不存在的覆盖文件会移除；共享菜单/文件窗口设置在最后一个模块恢复时还原。

依据：[LibreOffice 26.2 自定义指南](https://books.libreoffice.org/en/GS262/GS26213-CustomizingLO.html)、固定构建的[对话框加载实现](https://github.com/LibreOffice/core/blob/cd7284b4cbbfeb507e630c1aac019f4157393acb/vcl/source/window/builder.cxx)。配置文件存在不等于实际生效：验收读取独立实例的有效菜单，并检查实际窗口。
