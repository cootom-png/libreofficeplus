# LibreOfficePlus v6.6.1：界面间距排查与说明更新

本版把后续维护统一到 [cootom-png/libreofficeplus](https://github.com/cootom-png/libreofficeplus)，不再向 LibreOffice 官方提报。四模块的安装、菜单、快捷键和两个版本的兼容配置沿用 v6.6.0。

- 新增包内 `界面间距说明.txt`，解释短标签过宽、拉宽窗口及隐藏上下文标签时宽度变化的共同原因。
- 保存本体源码补丁参考、精确来源和三个基线的适用性检查，供本项目研究；资料位于本版本的仓库源码中，不由安装程序应用。
- 修复来源检查脚本在英文 Windows 上输出中文时的编码错误。
- 发布流程按版本读取发布说明，并继续核对最新 main、完整提交、配置包内容、兼容矩阵及 SHA-256。

**本版没有改变顶部选项卡宽度。** 这一改动需要修改并编译 LibreOffice 本体；本体补丁尚未完成 C++ 编译、CppUnit 和实机缩放验收。本次发布不包含修改后的 LibreOffice 程序，不将这些未完成项作为已修复功能。

解压完整 `LibreOfficePlus.zip`，双击 `安装.vbs`。支持的本体构建仍为 26.2.5.2 与 26.8.1.1；升级或降级本体后，重新配置此前使用的全部模块。首次备份继续保留。

发布工作流重新执行配置包构建、结构测试、安装/升级/降级/恢复和 WPF 界面检查，并校验本项目补丁资料的来源及适用性。实际检查结果见对应 GitHub Actions 记录；这些检查不替代 LibreOffice 本体测试。

本次发布使用本对话中用户的明确发布授权；不声称仓库存在未配置的 GitHub 环境审批保护。发布资产仅含配置包、`SHA256SUMS.txt` 与 `release.json`，保留 v6.6.0 等既有版本供回退。工作流临时产物保留 7 天，过期产物由既有保留机制清理。
