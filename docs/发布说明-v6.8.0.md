# LibreOfficePlus v6.8.0：Material 浅色外观

- 安装、恢复及兼容升级窗口改用浅灰蓝背景、白色卡片、圆角按钮、模块选择卡片和统一的进度/结果状态。
- Writer、Calc、Draw、Impress 通过原生浅色主题统一功能区、侧栏、菜单、输入框及工作区颜色；保留现有 WPS 习惯按钮位置、分组和快捷键。
- 外观值纳入首次备份；部分恢复保留通用主题，最后一个模块恢复时还原原值。继续支持三个已适配构建和受控兼容升级。

下载安装完整 ZIP，保存文档并退出 LibreOffice，运行 `安装.vbs` 给原有模块应用新外观。已有首次备份继续保留。

两个原生版本的有效配色安装/恢复检查通过，原生 Windows 样式另做颜色核验。原生菜单选中颜色、标题栏及部分圆角仍可能跟随系统，原生对话框内部排版和顶部选项卡宽度没有在本版重写。详情见包内 `Material外观.txt`。

本次合并与发布使用用户对本项目持续实施、提交、合并和发布的对话授权；只通过 GitHub Actions 对最新 main 的完整 SHA 构建、验收并发布，再下载资产核对。工作流产物保留 7 天，历史正式包和必要回退版本继续保留。
