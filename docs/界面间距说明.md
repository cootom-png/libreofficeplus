# 顶部选项卡间距说明

v6.6.1 是排查与说明更新，保留 v6.6.0 的四模块配置和两个已支持的 LibreOffice 构建，**没有缩小顶部选项卡宽度**。

Impress 的“开始、插入、设计”等短标签显得较宽，原因是 LibreOffice 本体在空间足够时将标签扩宽到至少 100 像素。Writer、Calc、Draw 使用的同类控件也受这段逻辑影响。窗口稍微拉宽，或图片、表格等上下文标签消失时，还可能触发其余标签突然变宽。

这些表现由本体控件计算，不能仅靠本配置包的界面文件消除。当前保留 LibreOffice 原生行为；重复安装、修改文字内容或改变文档样式都不是间距修复办法。

本轮检查了新旧两版、四模块共 8 份功能区界面文件。未发现通过配置强制扩展标签的证据；容器间距及边距最大值为 5 或 6。较宽的固定控件主要是线型选择和媒体工具区，不能为缩小空白而直接压缩其中的实际操作控件。不同缩放、主题和窄窗口仍需要逐项实机检查。

后续更新统一在 [LibreOfficePlus 仓库](https://github.com/cootom-png/libreofficeplus)维护和发布，不向 LibreOffice 官方提交 Issue、PR 或 Gerrit 评审。需要本体修改才能实现的改动暂列为配置包限制；源码补丁与来源校验资料保存在仓库，仅供开发研究，没有经过完整本体编译和界面验收，也不会由安装程序应用。

本版安装方法和恢复方式沿用原流程。更新前保存文档并完全关闭 LibreOffice，解压完整配置包后双击 `安装.vbs`；首次备份继续保留。发布页面提供文件校验值，旧版保留供回退。
