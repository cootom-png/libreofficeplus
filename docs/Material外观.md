# Material 浅色外观（v6.8.0）

保留现有 WPS 习惯功能区、按钮顺序、菜单分组和快捷键，按 Google Material 的清晰层级、浅色表面和重点操作配色优化外观。项目独立实现控件，不使用 Google 或 WPS 的品牌图形、专有皮肤、字体文件，也不宣称官方合作。

| 角色 | 颜色 | 用途 |
| --- | --- | --- |
| 主操作 | `#0B57D0` | 开始配置、焦点和重点操作 |
| 浅色容器 | `#D3E3FD` | 次级按钮、选中区域 |
| 工作区 | `#F0F4F9` | 安装窗口底色、文档周围背景 |
| 表面 / 正文 | `#F8FAFD` / `#1F1F1F` | 功能区、侧栏与正文控件 |

## 安装、恢复与升级窗口

取消深色渐变横幅，改为浅底、白色圆角卡片和蓝色胶囊按钮。四模块使用可键盘选择的卡片，路径框保留文本编辑与选择能力。开始前收起等待中的检查列表和进度，开始后展示实际阶段、线性进度和检查结果；成功与失败使用文字及不同状态标签。主要操作固定在底部，小窗口的内容可滚动。

安装、恢复与兼容升级共用同一套控件和颜色，继续保留环境检查、首次备份、版本拒绝、更新程序运行阻止及失败提示。

## Writer、Calc、Draw、Impress

通过原生浅色方案 `COLOR_SCHEME_LIBREOFFICE_LIGHT` 的可恢复用户覆盖，设置功能区、窗口、侧栏、菜单、输入框、分隔线与工作区配色；Calc 另调整网格与单元格焦点，Draw 调整网格。继续使用原生 Colibre 图标和紧凑功能区图标大小。文档内容、样式、字体和模板不因本次外观更新而重写。

采用内置浅色方案，避免创建无法恢复的额外主题节点。每个覆盖值纳入已有首次备份；全局主题在最后一个模块恢复时还原，模块专属网格设置随相应模块恢复。原来有自定义浅色颜色的用户，恢复后回到首次安装前的值。

## 兼容与验证边界

- 保留 26.2.5.2、26.2.6.1、26.8.1.1 的精确构建校验，两套功能区资源继续共用或按版本选择。
- 在 26.2.6.1 与 26.8.1.1 的独立配置中，42 项有效外观设置分别完成安装及恢复检查，见 [Material配色验收.json](Material配色验收.json)。使用受控配置副本隔离测试进程检查，不修改实际用户配置。
- 原生 Windows 样式检查另核验四模块的窗口/功能区表面、菜单背景与文字、输入框等实际样式颜色，记录在 [Material原生样式验收.json](Material原生样式验收.json)。这不等于全部像素或逐按钮验收。
- Windows 原生菜单选中颜色、标题栏、部分控件圆角及原生对话框内部排版仍可能跟随系统和 LibreOffice 本体。本包不承诺将所有控件变成 Material 控件，也没有修复顶部选项卡宽度或旧文档样式重排。
- LibreOffice 的外观主题是当前用户的全局设置，配置一个模块也会影响其他组件的通用外观。部分恢复不会提前还原全局颜色；全部恢复才恢复首次值。
