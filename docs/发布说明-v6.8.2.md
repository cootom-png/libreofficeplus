# LibreOfficePlus v6.8.2

补充 Windows x86-64 版 LibreOffice **26.2.4.2** 兼容，保留既有 WPS 操作布局、快捷键和 Material 浅色外观。

- 精确支持构建 `0229ac93fcf0d7cbc6376066c6f35021cef002dc`，来源为官方版本标签与官方安装分发；四套功能区和 24 个菜单共用已验证基线资源。
- Writer、Calc、Draw、Impress 均纳入同一安装、重复配置、版本切换及首次备份恢复流程。
- 兼容升级入口允许从 26.2.4.2 升级到已适配的 26.8.1.1，并重新配置原有模块；不会自动升级、自动降级或放行未知构建。
- 原有 26.2.5.2、26.2.6.1、26.2.6.3 与 26.8.1.1 支持继续保留，README、兼容说明和包内文档同步更新。

使用方法：下载并完整解压 `LibreOfficePlus.zip`，保存文档并退出 LibreOffice，运行 `安装.vbs`。版本切换后同时选择此前配置过的全部模块；首次恢复备份继续保留。无需为了安装界面配置包升级或降级 LibreOffice 本体。

验证记录见仓库 `docs/26.2.4.2兼容验收.json` 与 `docs/版本兼容.md`。真实窗口逐按钮、不同 DPI、复杂旧文档排版及真实 MSI/UAC/重启仍保留既有验证边界；本轮开发测试使用独立配置和合成文档，不改写个人文档。
