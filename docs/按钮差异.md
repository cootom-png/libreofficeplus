# 按钮位置与功能差异

当前以提供的 WPS 文字和表格截图为参考，优先减少常用操作的查找成本。

| 参考区域 | 当前处理 | 尚存差异 |
| --- | --- | --- |
| 开始：格式刷、剪贴板 | 格式刷独立大按钮置左；粘贴在其后，剪切/复制为小图标 | 像素间距和粘贴菜单样式不同 |
| 开始：字体 | 保留字体与字号输入框；清除格式移到字号旁 | 字号名称、字体默认值由原生设置或文档决定 |
| 文字：段落与样式 | 保留两行段落区和样式预览；增加样式窗格按钮 | 段落按钮分组、样式预览数量和侧栏外观不同 |
| 表格：对齐 | 换行/合并跟随对齐区，数字格式位于后面 | 两行小图标顺序与 WPS 仍有差异 |
| 表格：常用操作 | 增加填充、求和、排序、筛选、冻结、查找 | “填充”对应向下填充，不是 WPS 的完整填充菜单；小窗口会折叠 |
| 插入/页面/引用/审阅/视图/工具 | 原生容器中按参考顺序放置可对应命令 | 并非精确逐项布局，部分菜单与分隔符保留 |
| 表格：公式 | 提供函数向导、常用函数、名称、追踪、重算入口 | 尚无 WPS 式财务/逻辑/文本/日期分类菜单 |
| 打印相关按钮 | 打开原生页面格式或打印区域设置 | 原生窗口需自行选择选项，不能当作同名开关 |
| 数据区域与保护 | 用准确名称说明原生动作 | 数据区域不等于 WPS 的结构化表格，格式窗口不等于锁定切换 |

无本次已确认直接对应命令的朗读、限制编辑、重排窗口、允许编辑区域等入口被省略。命令在注册目录中存在只说明有原生入口，不代表在所有文档、选区或模块中都可用。

后续精确布局需要继续在原生容器内调整，并逐页检查。直接替换整页布局的试验出现过空白功能区，因此该试验方案未纳入交付。
