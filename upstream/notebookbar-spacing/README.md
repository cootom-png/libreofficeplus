# Notebookbar 选项卡间距修复

针对短名称选项卡被强制撑到 100 像素的问题，提供 **LibreOffice 本体源码补丁**。该补丁尚未进入官方版本，也不包含在 v6.6.0 一键配置包中；重新安装配置包不会改变本体的这段代码。

## 原因与修复范围

[上游 `NotebookbarTabControlBase::ImplPlaceTabs`](https://github.com/LibreOffice/core/blob/05700030c524742e408656375d8e34e00fe4df1a/vcl/source/control/tabctrl.cxx) 在空间足够时，把每个有文字的短选项卡扩宽到至少 100 像素。它先按这个宽度计算总长度，再决定是否扩宽。由此产生三种相关表现：

| 表现 | 原因 | 补丁处理 |
| --- | --- | --- |
| “开始、插入、设计”等短标签之间空白过大 | 与实际文字长度无关的 100 像素下限 | 使用原有文字、图标与原生边距测量结果 |
| 稍微拉宽窗口后，标签突然变宽 | 总长度跨过扩宽阈值 | 去除扩宽预计算与阈值分支 |
| 隐藏图片、表格等上下文标签后，其余标签变宽 | 可见标签数量改变了同一个阈值 | 可见性变化不再触发强制扩宽 |

这些行为来自同一控件，适用于使用它的 Writer、Calc、Draw、Impress，以及 Tabbed / Tabbed Compact 布局。后两项是依据代码确认的关联行为，尚未完成改动后的实机视觉验收。

补丁不指定统一的 50 或 60 像素宽度；中文、英文、较长名称继续按字体和原生主题计算。保留原有最小高度、快捷工具区预留、右侧菜单和普通对话框的选项卡布局。删除同一函数中不再需要的总宽度循环及未被读取的行宽数组。

## 同类问题排查

检查对象为 v6.6.0 生成的两版、四模块共 **8 份 `notebookbar.ui`**，结果如下：

| 项目 | 静态检查结果 | 处理 |
| --- | --- | --- |
| 选项卡 `tab-fill` / `tab-expand`（含 `packing` 属性） | 已出现的 `tab-fill` 全为 `False`；没有 `tab-expand=True` | 没有配置强制扩展的证据，无需通过配置包改写 |
| 容器 `spacing` / `margin*` | 最大值为 5 或 6；未发现大于等于 8 的设置 | 没有证据支持全局压缩 |
| 不小于 100 的 `width-request` | 分布在线型选择、媒体工具区，不是顶部标签 | 保留有内容的控件宽度，待相应操作场景实测 |
| 同一宽度分支中的无效计算 | `nLineWidthAry` 只写不读，预计算仅服务于强制扩宽 | 随本补丁删除 |
| 高 DPI、超窄窗口、原生主题和键盘焦点 | 静态检查不能证明视觉结果 | 列入后续本体编译验收，不宣称已修复 |

这里只参考常见办公软件的紧凑操作习惯。补丁使用 LibreOffice 自身控件与测量逻辑，不引入 WPS 图标、商标、截图或专有代码。

在本项目根目录执行 `python scripts/check_upstream_spacing.py` 可从官方镜像重新下载固定文件、校验来源、核对补丁修改范围，并在临时目录试应用。CI 同样执行此检查。**这不是 C++ 编译或 CppUnit 通过的证明。**

补丁新增 `CppunitTest_vcl_notebookbar`，直接测试真实 VCL 控件：

- 短中文、英文、长名称与空标签的宽度，和普通选项卡的原生测量结果比较；覆盖三档字体大小。
- 窗口跨过旧扩宽阈值时宽度保持一致，快捷工具区和右侧菜单仍留有空间。
- 隐藏、恢复上下文标签时，其余标签宽度和当前页保持稳定。

## 官方提交与后续验收

[LibreOffice/core 的 GitHub 页面](https://github.com/LibreOffice/core) 明确标注为只读镜像，要求通过 [Gerrit](https://gerrit.libreoffice.org/) 提交代码。本次已准备可审阅补丁，但没有已认证的 Gerrit 会话，因此 **尚未提交到官方 Gerrit，也没有官方评审编号**。本项目 PR 用来审阅、保存补丁和跟踪验收，不能视为官方已接收。

后续执行顺序：

1. 在完整 LibreOffice 开发环境中，检出 `source.json` 对应提交，执行 `git apply --check` 后应用 `tab-width.patch`。
2. 运行 `make CppunitTest_vcl_notebookbar`，确认未修复版本触发回归、修复版本通过；本机缺少所需 C++ 构建环境，此项未执行。
3. 在 Windows 四模块、Tabbed / Tabbed Compact 中验证最大化和窄窗口、中文/英文名称、上下文切换、快捷工具区、菜单点击、键盘焦点与 100% / 125% / 150% 缩放；补丁后实机结果尚未验证。
4. 在认证后的 Gerrit 提交补丁与真实测试结果，按官方评审意见调整。两条稳定分支是否接收回移由上游维护者决定；补丁可应用不等于官方兼容性承诺。
5. 官方合入或完成独立本体构建与验收后，再决定是否提供新本体下载。配置包版本保持 v6.6.0，不发布一个仅改版本号却没有间距修复的 ZIP。

补丁基于 LibreOffice 源码，遵循原文件的 MPL 2.0 许可与来源声明；新增测试及构建文件保留 MPL 2.0 文件头。`tabctrl.cxx` 原有 ASF 来源声明由上游源文件继续保留。完整 MPL 文本见本项目根目录 `LICENSE`。
